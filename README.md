# Agent

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

macOS 安装包：[前往下载](https://github.com/enkin-japan/Agent-L0/releases/tag/updates)。

Agent 是一个本地优先的 AI 桌面助手。用自然语言交代任务，让它帮你查资料、整理文档、处理文件，或完成需要多个步骤的工作。

你可以通过 macOS、iOS 或浏览器使用它。模型可以运行在自己的 Apple Silicon Mac 上，也可以交给另一台支持 MLX 或 CUDA 的电脑处理。

## 能帮你做什么

- **查资料、读文件**：结合网页、PDF、办公文档、图片和音频回答问题，整理要点。
- **建立个人知识库**：保存资料，按主题管理，在后续对话中检索和引用。
- **完成多步任务**：查看计划与执行进度，在需要时确认操作、暂停或停止任务。
- **交付文件和演示文稿**：在对话旁查看生成的文件、下载成果，预览 Deck 幻灯片。
- **安排定时任务**：设置周期性工作，查看运行结果和历史记录。
- **连接自己的服务**：添加私人 API 工具，让 Agent 使用你配置的服务。

例如，你可以这样开始：

> 阅读这几份 PDF，比较它们的主要结论，并整理成一份报告。
>
> 根据这份资料制作一套演示文稿，先给我看大纲。
>
> 每个工作日上午整理我关注的行业新闻。

可用功能取决于所选模型、已连接的服务和授予的权限。

## 开始使用

### 使用客户端

macOS 客户端可在本机运行 Agent，也可连接独立的算力设备。先在设置中完成服务连接；使用远程算力时，填写对应地址与连接密钥。

iPhone、iPad 作为客户端连接已经运行的 Agent，不在手机上加载模型。跨设备访问建议使用 Tailscale 等受信网络。客户端的构建、连接方式见 [Apple 客户端说明](apple-app/README.md)。

如果 Agent 已部署好，也可以直接在浏览器中打开它的 Web 地址。本机默认是 `http://localhost:5173`。

### 自行部署

需要 Python 3.11–3.13、Node.js/npm，以及所选模型需要的内存或显存。首次加载模型可能需要下载较大的文件。

在仓库根目录安装依赖：

```bash
./devctl.sh setup
```

然后选择运行方式：

| 运行方式 | 配置与启动 |
|---|---|
| 在一台 Mac 上运行 | 将 `config.yaml` 中的 `inference.mode` 设为 `inprocess`，保持 `rag.compute.host` 为空，并移除 `.env.local` 中的 `RAG_COMPUTE_HOST` 覆盖。运行 `./devctl.sh start`。 |
| 使用另一台电脑的算力 | 在两端配置地址与密钥，算力端运行 `./devctl.sh start --profile gpu`，使用端运行 `./devctl.sh start --profile edge -h <算力端地址>`。 |

仓库初始配置使用远程模式，但没有预填地址。请先完成配置，或切换为单机模式，再启动服务。分离部署的连接与密钥说明见 [部署架构](ARCHITECTURE.md)。

启动后打开 `http://localhost:5173`。常用管理命令：

```bash
./devctl.sh status         # 查看服务状态
./devctl.sh logs backend   # 查看运行日志
./devctl.sh stop           # 停止服务
```

## 日常使用

**上传资料再提问。** 将文件添加到对话中，说明希望得到的结果。任务完成后，可在文件页找回生成的附件；幻灯片在 Deck 页面预览。

**需要确认时，先看清操作内容。** Agent 会对需要审批的工具调用请求确认。定时任务无人值守时不会自动批准这类操作。

**停止和重试有不同含义。** 停止会在安全点阻止后续执行，已经写入的文件或发出的外部操作不会自动撤销。重试会沿用原附件和生成设置，也可能再次调用工具；成功后显示新的结果，之前的尝试仍可查看。

**保留重要会话。** 会话及其生成文件受保留期限管理，可以通过置顶保留重要内容。具体期限以应用显示为准。

**更换知识库模型后按提示重建。** macOS 知识库页面可以检查状态并发起重建。选择“稍后”后，仍可回到这里继续。自行部署时可用以下命令选择模型：

```bash
./devctl.sh model       # 选择对话模型
./devctl.sh rag-model   # 选择知识库模型档位
```

**连接私人 API 时，在 macOS/iOS 客户端的工具设置中填写密钥。** 确认添加工具后可以继续配置，无需重新输入整份声明。工具出现在清单中不代表连接已验证；试调可能产生实际操作，请确认用途后再执行。

## 数据与隐私

会话记录和知识库保存在运行 Agent 的工作电脑上。使用独立算力设备时，处理任务所需的输入会发送到该设备；联网搜索、私人 API 和可选云端顾问也会访问相应的外部服务。

算力设备可能暂存用于推理的媒体；启用 KV 缓存持久化后，还会保存与会话有关的缓存。相关保留和清理设置见 [部署架构](ARCHITECTURE.md)。

服务只应通过受信网络访问。Web 入口使用服务器保存的连接密钥，能访问该入口的设备就能使用 Agent，请勿直接向公网开放。
