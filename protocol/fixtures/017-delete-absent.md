# 017 — 删除不存在的会话（HTTP 回执）

这是 HTTP 管理响应夹具，不是轮次事件流，不改变共享事件归约结果。

- `absent`：服务端确认没有热实例和目录；保留旧 `status: false` 语义，新增 `reason: not_found`。客户端可据此移除本地空会话或已失效的缓存，因为删除目标已不存在。
- `deleted`：正常删除成功。
- `failed`：一般拒绝或文件删除失败，仍须保留本地条目和失败选择，不能当作不存在。

清理只针对原请求持有的会话及 receipt；选择/连接发生变化不能清除新状态。未带 `reason` 的旧端失败仍作失败处理，不靠翻译文案判断。此回执不承诺未来或其他客户端不能用同一 ID 发起新请求。
