## 结论一览

1. **MTP 加速比随上下文单调衰减，gemma 全家族在 Agent 常驻区间（4k–32k）跌穿 1.0 变净亏**。
   最好的 31b-8bit 也在 ~32k 打平；26b/31b 的 4bit 档在 64k 跌到 0.36×–0.47×。
   §6.3 那些 1.4×–2.5× 的定档数字只在单轮冷启动（ctx≈0）成立。
2. **Qwen3.8 内建 MTP 头（8bit/4bit 两档）是全库唯一全 ctx 段净赚的形态**：
   8bit 1.70×@0 → 1.27×@64k，4bit 1.54×@0 → 1.21×@64k；接受率横跨 ctx 不劣化
   （8bit 33–36% @γ4，4bit 50–58% @γ2）。机制：草稿成本近零（1 层头共享主干），
   只剩验证步的 attention 放大项。
3. **Agent 场景 MTP 判定：gemma 家族不可用**（解码净亏 + A8 每轮冷预填双重损失）；
   qwen38 两档解码段成立，但生产开启仍前置 A8 多轮净收益实测。
4. 12b/e4b 的 MTP×ctx 臂判定不测：更小目标件 + 外挂草稿件，衰减只会比 26b/31b 更陡，
   对结论零增量。
5. **质量侧：gemma 全家族 tool_call 系统性失分**（详见下），Qwen 家族全维度占优。
6. **26B 缺省档之争裁决**：质量打平（差异全在噪声带内），4bit 速度 1.34× / 体积省 12G
   → **26b-4bit 胜出**。QAT 档质量、速度双双不占优 → 维持 PTQ 判决。

### 判读

- **gemma tool_call 系统性失分（本战役最大质量发现）**：26b×3、31b×3、12b-8bit 七个档
  **逐指标完全相同**（0.72 / 0.70 / 解析错 12 / turns 41），跨尺寸（12B→31B）、跨量化
  （4bit/8bit/QAT）、跨架构（稠密/MoE）不变；对照 Qwen 家族解析错为 0。这不是模型能力
  梯度，是 **gemma4 方言工具 DSL 链路的系统性问题**（同一批题以同样方式解析失败，且
  纠错回喂成功率 0%——错了就再也回不来）。26b-8bit 与 08-15 历史 run 逐指标复现，判分
  确定性成立。→ 架构侧待办：定位这 12 次解析错在方言组装/parser 哪一环，属"架构锅"
  而非"模型锅"。**在此修复之前，gemma 档的 tool 列不能当模型能力读**。
- **26B 之争**（沿革：08-14 哨兵矩阵无法裁决，留 model_eval）：tool 完全同分；长链
  6 题差 1 题级别；vision 0.87 vs 0.84（212 题差 ~6 题，路由噪声带 0.05 内）。质量判平，
  4bit 速度 101 vs 75（引擎口径）/ 122 vs 80（server 口径），内存省 12G → **缺省档定
  26b-4bit**。08-14 哨兵的弱信号（长 ctx×结构化输出）可在路由层规避（长上下文工具场景
  给 8bit），不推翻缺省判决。
- **QAT 两件收案**（沿革：§S.16 撤销"A 毒"后挂起待评）：26b-qat 质量（长链 0.83 /
  vision 0.82）与速度（94 vs 101）都不优于 PTQ-4bit → **26b-qat 无入列理由**。
  31b-qat 质量与 31b-8bit 打平（vision 0.93 / 长链 1.00），速度 18.4 vs 16.0，且有
  64k 不 OOM 的独有硬优势 → **31b-qat 作为 31B 长上下文档的地位坐实**。
- **12b-4bit 是全库唯一质量实跌的量化档**：vision 0.74 vs 8bit 的 0.82（212 题差 17 题，
  远超噪声带），tool 也掉（0.68/解析错之外的失分）。12B 档若入路由，vision 活给 8bit。
- **e4b 新钉口径画像回填**（沿革：旧画像 stale-revision）：tool 0.64 略低于大档的 0.72
  （少 2 题级别+解析错 10-12），vision 0.84/0.88 与 26b 持平。
- **Ornith 长链 0.33 vs 旧画像 0.67**：题库/评分器自 07-30 起有扩容演化，先记"复核待办"
  不下回退结论；tool 0.96/首发 1.00 与旧画像一致。
- **跨家族**：Qwen3.5-9B（6GB）以 0.96/1.00/0.95 全面压过所有 gemma 档——在"模型×方言
  ×agent 循环"的组合口径下，方言链路质量把模型能力差距完全反转。

### 判读

- gemma 外挂草稿件形态：草稿件自身要为长上下文付全套 attention，验证步再为 γ+1 个位置
  付一遍——权重读摊销红利在 KV 主导区被吃光，衰减必然。跨越 1.0 的位置：26b 家族 4-8k、
  31b-4bit/qat 16k 前后、31b-8bit ~32k。
- qwen 内建头形态：草稿近零成本 + 接受率不随 ctx 劣化 → 衰减只剩验证步放大项，64k 仍
  +27%。**结构判定：外挂整件草稿这条路线对 Agent 负载已证死，内建头是唯一活路。**
- 与 §6.3 冷启动定档不矛盾但必须降格：那张表全部是 ctx≈0 单轮口径（本战役 ctx0 列与其
  方向一致，数值差异来自采样/块/口径差，如 26b-8bit 1.20× vs 1.41×——v3 真贪心的基线本身
  更快，且 rep 处理器关闭改变两臂成本比）。
- **A8 未解**：drafter 模式丢前缀复用、每轮冷预填，本表全部是单轮口径——qwen38-8bit
  要进 Agent 生产，A8 多轮净收益是最后一道前置（维持 §6.3 的"mode 扳 drafter 前必测
  A8 且用户拍板"红线）。
