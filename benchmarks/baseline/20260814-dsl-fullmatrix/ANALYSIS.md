失败集恰好等于「**被 JSON 格式压垮的弱档 + 长上下文**」：弱档整列翻正，强档只在
长上下文端零星翻正。这与迁移前的判断吻合——模型在自建 JSON 上"能用但吃力"，
吃力程度随档位变弱、上下文变长而放大。
