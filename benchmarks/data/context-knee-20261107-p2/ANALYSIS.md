## 1. 结论
1. **seed 生效：同输入的臂逐字相同，同臂不同 rep 全不同（V1）。** L0 按 (题, rep) 比较模型输出（每轮 thoughts / text / tool_calls 含参数 + 末轮答复；gens 比 turns 多出的生成记其 token 数与截断 / 取消标记）：none / w1 / w1w2 / catalog 两两 60/60 = 100% 逐字相同，首 prompt token 数与 system.json sha 也 60/60 相同；full 与其余四臂输出 0/60 相同（首 prompt 13,900 对 6,164）；全 5 臂 0/60。同臂内同题不同 rep 两两 0/150（五臂皆然），种子核对 0 条异常、每个 rep 跨臂跨档只有一个种子值（V1a–V1c）。所以 vLLM 逐请求 seed 生效且推理确定：**本批不是独立抽样，而是共同随机数设计**。填充档上 w1w2 与 catalog 全档逐字相同（catalog 臂整臂 120 run 是 w1w2 的复制，零新信息；Q 节、U3 的「catalog − w1w2 = 0」是构造使然）；32K 档 none 与 w1 20/20 相同（W1 在 32K 没有改变任何输出）；w1 与 w1w2 在三个填充档各 11/20 相同（W2 没触发的 run）；49K / 57K 档 none 与各管理臂 0/20（首次生成前 fold，输入就不同）。只在输出分叉的 (题, rep) 对上做符号检验（V1d）：none–w1 全档 b 赢 / a 赢 5/8（p 0.58），none–w1w2 5/9（0.42），w1–w1w2 0/1（1.00），w1w2–full 20/11（0.15），四个同类臂对 full 的 L0 都是 12/5（0.14）——没有一对显著。
2. **噪声基线（V2）：L0 独立样本只有两份**——{none, w1, w1w2, catalog} 一类、{full} 一类。none 类各 rep 通过率 40/60/70/40/60/50%（均 53.3%，rep 间 SD 12.1 点），full 70/60/70/60/70/60%（均 65.0%，SD 5.5 点）；6 rep 合计 32/60 与 39/60，按题聚类 bootstrap 95% CI [28,77] 与 [40,87]（宽 48 / 47 点，题间异质主导：10 题里 2 题 6/6 恒过、2 题 0/6 恒败，V2a、V2b）。**门槛定义**：把同臂 6 rep 拆成两组不相交的 m 个 rep 当两条假臂，枚举全部拆分得 |差| 的零分布，门槛 t = 使 P(|Δ| ≥ t) ≤ 5% 的最小可取值（零分布离散，直接计尾概率）。**同档两臂（10 题 × 2 rep，m=2，两类合并 90 个拆分）：成功率差 ≥ 25 点（P = 2.2%；P(≥20) = 8.9%）、Pass^2 差 ≥ 30 点（P = 2.2%；P(≥20) = 26.7%）才超出 rep 噪声**；L0 两臂各 6 rep 时以 m=3 拆分值作参考（20 个拆分：成功率 ≥ 20 点 P = 5.0%，P(≥13.3) = 15.0%；Pass^2 ≥ 20 点 P = 5.0%），6 对 6 的真实噪声更小，m=3 值偏保守（V2c）。解析近似值 1.96·s·√(2/m)：m=2 18.4 点、m=6 10.6 点，其中 s = 9.4 点由 12.1 与 5.5 两个 SD 合并，本身不确定性大，只作对照（V2d）。拆分共用 rep，尾概率是近似；部分逐字相同的臂对（未分叉的 run 差恒 0）用这个零分布偏保守，见 V1d。四个逐字相同臂之间的 L0 差恒 0、CI 零宽，不是零效应证据。
3. **P2 门槛（无管理臂 L0 ≥ 70%）：未达只按点估计成立。** none 32/60 = 53%，按题聚类 bootstrap 95% CI [28,77]，含 70%（V2b）；前 2 rep（与旧批 n=2 设计对齐）10/20，d44 7/20、b2 12/20（V3）。同期 full 形态（d44 w1w2 同形态）39/60 = 65% [40,87]。CI 宽主要来自 10 题之间的异质，不是 rep 噪声：门槛判断要么看点估计，要么换更多题。
4. **五臂拐点（V3，Pass^2、drop 0.20）：prod 三臂与 catalog 拐点 49152（L0 基线 41%，32K 30%、49K 10%、57K 10–20%）；full 拐点 32768（L0 55%，三填充档都 10%）。** d44 / b2 全部 32768（d44 none 基线 20% 在地板空判）。drop 0.20 小于 2-rep Pass^2 的噪声门槛（30 点），拐点落在 32K 还是 49K 在噪声内不可区分，只报数字。
5. **full 对 catalog（= D44 (iii) 生产现状）：没有 catalog 更差的证据（V4）。** catalog − full 按档（尾概率 = V2c 零分布 P(|Δ| ≥ 观察差)；L0 用 m=3，填充档用 m=2）：成功率 L0 −11.7（P = 15.0%）、32K −5（72.2%）、49K −5（72.2%）、57K +0；Pass^2 L0 −13.3（30.0%）、32K +20（26.7%）、49K +0、57K +10（73.3%）——**全部在噪声内**（32K 的 Pass^2 +20 不再算超门槛）。按题聚类 bootstrap 95% CI：L0 成功率 [−26.7, +0.0]、Pass^2 [−31.3, +3.3]；四档合并成功率 −5.4 [−15.0, +4.2]、Pass^2 +4.2 [−4.8, +15.0]；三填充档合并成功率 −3.3 [−13.3, +8.3]、Pass^2 +10.0 [+0.0, +26.7]。E / Q / U3 节里 analyze.paired_units 的成功率两段重抽区间（如 L0 [−32,+5]）把 rep 方差重复计入、偏宽，本稿不用。首 prompt L0 6,164 对 13,900（V4）。D44 (iii) 的直接效果：catalog 臂预检回执 run_math 从 d44 的 10 条降到 0，本批 prod 三臂与 catalog 只剩 move_file 1–2 条，full 0 条（Q、U3）；catalog L0 首 prompt 中位 5,472 → 6,164（+693，core 加两件；V4）。
6. **与 d44 同形态臂（V3b；L0 取本批前 2 rep 与 d44 的 2 rep 对齐，尾概率用 m=2）**：成功率差全部在噪声内（最大 none L0 +15，P = 17.8%；full 对 d44 w1w2 32K +15，P = 17.8%）；Pass^2 差只有 w1w2 32K +30（P = 2.2%）达到门槛，none 32K / catalog 32K / none L0 / full L0 的 +20 都是 P = 26.7%，噪声内。V3b 共 20 行 × 2 指标 = 40 个比较，出现 1 个 P ≈ 2% 不足为凭（多重比较，推断）；catalog 32K 与 w1w2 32K 本批逐字相同，不是两份独立证据。口径差：prod 生效前缀 full → catalog、d44 无 seed、两批之间还有 D44 (iii) 以外的改动，跨批差不能单独归因。E 节 none L0 +18 / +21 用的是 6 rep 对 2 rep 与两段重抽区间，本稿不用。
7. **时长（V5）**：五臂各 104–113 min，d44 四臂 86–91 min；L0 多 4 rep 按 L0 Σwall × 4/6 估约 18 min / 臂（full 21 min），与墙钟增量（none +22.1、w1 +18.0、w1w2 +22.0、catalog +23.0、full 对 d44 w1w2 +17.0 min）同量级。五臂合计 543.6 min；全批首行 → DONE 9.33 h（d44 6.13 h）。
8. **数据质量**：五臂 600 行 error 0、重复 0；连贯率 none 98/98、管理臂 100%、full 94/95（1 run 含假名 / 谚文，lc-hard-001 L0）；N 节记账核对全 0（M、N）。

9. **两题恒败的根因是步数超限，不是题坏（主会话自查，证据 `item004_008_evidence` 见 §2 末）。** lc-hard-004 / 008 在直调参照批（`../context-knee-20261031/qwen-current/`，L0）各 2/2 通过，用 8 步 / 7 步、redundant_calls 0；编排器五臂每题 12 run 的步数众数 13 / 12（预算 11 / 10）、redundant_calls 众数 3 / 2，判败理由主体是纯「步数超限」（004：none 6、w1 8、w1w2 8、full 5；008：none 8、w1 9、w1w2 9、full 6，各 /12），这些 run 的 state_ok 与 final_text_ok 都为真，收尾答复逐文件写「verified by re-reading」。其余判败是回合上限耗尽 / 无收尾答复（每臂 1–3 run）与 full 臂 1 run context_guard（39 步）；真正环境态错的只有 none / w1 / w1w2 各 1 run。即编排器路径比直调多约 5 步，其中 3 步是写完后逐文件回读验证，恰好撞预算。修掉冗余回读后 none 类 L0 可望多过这 2 题（6 rep 口径 ≈ 73%），P2 门槛 (a) 可达。

## 2. 口径缺陷与待修
- **prod 臂行内前缀元数据与实际不符**：`run_knee.build_prefixes` 对 `--prefix prod` 用 `production_decl("prod")`，在 D44 (iii) 后仍算 full 声明——`prefix_base_tokens` 13757、`prefix_n_tools.prompt_full` 60、`prefix_core_skipped` []；而实际送入的与 catalog 臂相同，证据是首 prompt token 数逐对相同、sessions/*/system.json sha 相同、输出 60/60 逐字相同（system.json 不含工具声明，none–full 也同，单看它分不出前缀；transcripts 不存 prompt 原文，不是原文比对）。I 节标题「prefix prod」、N 节末列、Q 节 prefix_base 列照抄行字段，读的时候按 catalog 理解；F 节本批已改取 catalog 臂 6022。建议 harness 按 `tool_schema_mode_effective` 计 prefix_base（推断，未改）。
- **成功率两段 bootstrap 对共同随机数数据不配对（analyze.py 既有缺陷，本波不改）**：`analyze.paired_units` 的 success_rate 区间对两侧各自在题内重抽 rep，逐字相同的两臂也得出非零宽 CI（w1w2 → catalog L0 +0 [−12,+12]、49K [−15,+15]、57K [−10,+10]；E、U3）。V4 已改用 analyze_p2.paired_item（只按题重抽）；E / Q / U3 节仍是旧区间，本稿结论不引用。Pass^2 只按题重抽，不受影响。
- 拆分零分布只有 L0 的两份独立样本（每类 45 个 m=2 拆分 / 10 个 m=3 拆分），拆分共用 rep，零分布离散（成功率步长 5 点、Pass^2 步长 10 点），尾概率是近似；填充档的题级通过率分布与 L0 不同（更多 0/2），门槛对那些档偏保守；部分逐字相同的臂对也偏保守（V1d 补了分叉对符号检验）。
- `output_sig` 对 gens 比 turns 多出来的生成（V1a 计数行：13 行，32K 4、57K 9）只能比 token 数与截断 / 取消标记，transcripts 不存其文本；另 1 行 gens 比 turns 少（full 57K lc-hard-004 r0），turns 全部进签名、不受影响。一审「14 行 len(gens)≠len(turns)」= 13 + 1。
- catalog 臂在本批与 w1w2 逐字相同，下一批若不再比 catalog / prod 差异可删这一臂（约 109 min / 批，V5）。
- 首次起机 rc=4（state=stopping before READY），READY_RETRY=1 自动重试成功；未影响数据，记档。
- 11-05 残项（线索重建口径、recall_source 配对、harness 不种任务）本批未改，见 d44 ANALYSIS §2。
- 服务端 vLLM 日志（per-request generator / 慢采样告警）本批无法核：本地 `.colab-compute/deploy.log` 对 VM infer.log 的镜像只到 READY 为止，运行期日志随 VM 释放丢失。seed 生效已由 V1 逐字相同率实证；时长增量（+17–23 min / 臂）与 L0 多 4 rep 的估计同量级，看不出慢采样路径。建议 run_colab.sh 停机前 `deploy.sh logs --remote` 抓一次（推断，未改）。
- 两题恒败根因的逐 run 统计留档：`item004_008_evidence.md`（本目录）。

## 3. 待拍板（analyst 起草，主会话改定建议）
