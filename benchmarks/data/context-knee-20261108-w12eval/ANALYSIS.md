## §3 建议（主会话）

1. **判语：现行参数的 W1/W2 管理栈（D1/D2 soft 24,576 / hard 39,322 / ceiling 53,248）在拐点以上「不优于」无管理，P2 出口未达。** §2 第一条点估不满足（成功率合并比 0.90 [0.77,1.10] 压线，Pass^2 合并比 0.75 [0.56,1.04]，49K 0.67 [0.33,0.96]、57K 0.51）；第二条按设计不可能满足（soft 24,576 本身高于 0.7 × 32,768 = 22,938，0/180 过线）；第三条满足（Σwall −7.1%）。按 11-08 晚预案：不改 §2 第一条，回到 W1 落刀 / W2 触发点 / 57K pre-fold 设计。

3. **机制上的硬证据在 57K 与 49K（§1.10）。** 57K：w1w2 60/60 在首次生成前 fold 到中位 27,158 tok（比 none 的 57,554 短 53%），Pass^2 却 26.0% → 13.3%、成功率 45.0% → 38.3%；none 看完整 57K prompt 仍守住平台。49K：hard 首生成前触发 60/60、hard 级 step_compaction 22 次 + 后续 ceiling fold 8 次，−11.7 / −10.0。32K：只有 soft 级 step_compaction 41 次，+5.0 / +3.3，中性偏正。读法：在 max_model_len 65,536 以内，Qwen3.8-27B 自己处理 49–57K 上下文比我们的 fold 摘要更保真，fold 的信息损失大于长上下文衰减。设计方向：soft 级逐步压缩可留；hard / ceiling 的整体 fold 在窗内是净负，其价值只能是防溢出，不能指望抬成功率。
