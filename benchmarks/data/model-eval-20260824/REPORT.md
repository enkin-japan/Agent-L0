## 结论（按用户五问）

### 1. 题库扩容
新增 84 题入库（生产工具面 tc-real 30 / 长链加难 lc-hard 10 / 通用指令遵循 tx-gen 32
含多轮 history 与日语 / 合成 App 截图 vi-app 12），配套 `tools_ref`→46 个生产工具
schema 快照、mock 环境故障注入（fail_first_n / readonly / office 合体）、executor 多轮
history。合库规模 108 → 192 题。剔坏题两道工序：26b-4bit 先行整跑（修 2 题面、放宽 1
判分），reviewer 一审 5 条实质判分缺陷全修（CJK `\b` 词边界等）；七档跑完后全员失败题
仅 1 道（tc-real-020），按"共同失败=坏题探测"裁决为题面缺陷（run_shell_command 自称
PRIMARY 却当干扰项），剔干扰项后单题七档补跑并入档（superseded 留痕）。**新批区分度
达成：分歧题 24 道，旧批里 tool_call/seed、vision/chartqa(易) 等天花板批依旧全对——
区分度全部来自新批与 chartqa_hard。**

### 2. Ornith-1.5-35B-A3B 入册
三档 MLX 量化均为**纯文本件**（无视觉塔——官方 bf16 支持图像，MLX 转换只发了文本塔；
权重 0 个 vision_tower 键为准）。装载经 `backends/mlx/patch/text_only_vlm.py`（窄谓词：
仅 vision/audio/dflash 全空的 qwen3_5 系 config 生效）。方言 qwen35 零解析错误跑通全程
（55+16+48 题 ×3 档，parse_errors 合计 1）。蒸馏痕迹：自称 "Claude, made by Anthropic"。

### 3. Ornith-1.5 全方位测试 + 6bit 判定
- **质量**：tool_call 0.836/0.800/0.800（4/6/8bit）、longchain 0.875/0.812/0.812、
  text 0.771/0.771/0.750。4bit≥8bit 差距 1–2 题 = 噪声级；**判定规则（≥3pt）机械触发了
  6bit 补测，结果 6bit≈8bit≈4bit，无独立生态位——本家族只留 4bit 有意义**。
- **速度**（bench v3）：4bit decode 117.5→76.5 tps（ctx 0→64k）、prefill 1856 tps@4k、
  峰值 27.6G@64k、TTFT 61s@64k。是全库 64k 段最快的档（gemma26b-4bit 同点 61.6 tps）。
  chat 负载中位 85.8 tps。MTP 未测（用户指定不做；config 里 mtp 头也未随 MLX 件发布）。
- **行为画像**：探索先行（先 find_files/list_dir/读文件再动手、删列前先备份）——
  在单发择器题上系统性吃亏（tc-real-020 修订版仍先核实后动手），但**长链最省**：
  步数合计 101（gemma26b-4bit 154）、复读调用 9（gemma 64）、终态达成 93.8% 全场最高
  （4bit）。Terminal-Bench 训练的痕迹与本项目"一步到位调用"的期望存在风格差，
  报告按行为差异记录，不全计为能力缺陷。
- **弱项**：长上下文结构化聚合与全场一致地差（longctx_struct 5/16，同 26b 的 B3 边界）；
  思考正文转述率 16–18% 偏高（qwen38 7–8%）。

### 4. gemma-26b / Qwen3.8 重测（扩容题库口径）
- **gemma26b**：tool_call 0.909/0.927（4/8bit）全场最高——生产工具面批 26–27/30，
  果断单发风格与题库期望契合；text 0.708 全场最低（tx-gen 30/32 尚可，长上下文
  结构化 4/16 拖累）；vision 0.871/0.866（chartqa_hard 85%）。
- **qwen38**：text 0.854/0.875 与 vision 0.955/0.964 全场最高（B1/B3 边界的既有分工
  再次确认）；tool_call 0.818（4bit）为其最弱面——生产工具面 22/30，失败样式与
  Ornith 同类（探索先行/shell 倾向）+ 少量参数类型不忠实。longchain 8bit 0.938 全场最高。
- 与旧画像的数字回落（如 tool_call 0.92→0.909）**不是退化**，是题库变难：旧批部分
  在新一轮里依旧满分/接近满分。config 注册表 profile 已统一回填 08-24 口径（含新维 text）。

### 5. 路由启示（数字→ 分工）
- 26b-4bit 继续当**工具执行主档**（tool_call 最高、内存最小、decode 快）。
- qwen38 继续当**vision/文本理解特长位**（0.955+/0.87 text），tool_call 弱面新确认
  ——涉及"多工具在场选对"的任务不宜路由给它。
- Ornith-1.5-4bit 定位**纯文本长上下文/多步文件任务备选**：64k 段速度全场第一、
  长链终态最高、25G 峰值可与 vision 需求错峰；无 vision、单发择器弱是硬边界。
  是否入 endpoints 与产线由用户拍板（本次仅入册画像，不改 model 选择）。
- B3（隐式聚合弱）为全家族通病（新证据：七档 longctx table 批 25–62%），
  run_math tool_assist 护栏的适用面覆盖新入册档。
