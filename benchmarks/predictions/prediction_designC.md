# Design C（26b-8bit 组件级归因）——开跑前预测（2026-08-15，v1.2）

## v1.2 修订记录（v1.1 首跑 P1 失败，按承诺整组作废后重设计；本节先于 v2 首跑写下）

v1.1 首跑（作废，数据不采信）暴露的探针病根：**每次探针调用带 ~0.22 ms 的
固定同步开销**（kernel launch + 管线排干），把小组件的比值整体稀释——
dense_mlp 的瓦片跳变被稀释到 1.07，P1 按底线 1.3 判失败（正确触发）。
预标定的 c=0.2µs 量的是"对已求值数组的空 eval"，与真实开销差三个数量级，
校正形同虚设。

v2 设计变更（唯一变更）：**router 作在跑零参照**。Router 的真实计算是
2816→128 的小矩阵乘 + argpartition（~1µs 量级），v1.1 实测 0.222/0.224/0.219 ms
且跨 L 恒定 ⇒ 它测到的就是"纯探针开销 o(run,L)"。v2 逐 (run,L) 用
`t̂ = m − m_router` 校正后再算比值。判据随之改挂在校正值上：

- **P1'（硬对照）**：dense_mlp 的 t̂(6)/t̂(4) ∈ [1.5, 2.2]；<1.3 整组作废。
  lm_head 降为**软对照**（只报不判）：它每步只调一次，排干口径与逐层的
  router 零参照不完全匹配，预期它的校正比值偏低（v1.1 数据折算 ≈1.4~1.5）。
- **P2'（主判据）**：experts 的 t̂(4)/t̂(1)，阈值不变（≥2.15 内核残差 /
  ≤1.95 缓存已满 / 其间灰区不强判）。v1.1 作废数据折算约 2.4——
  我押 **2.2–2.5（残差在专家内核）**，但以 v2 实跑为准。
- t̂ ≤ 20µs 的格标"不可靠"不参与判定（减法后残差太小）。
- 其余 P3/P4/P5/P6 与漂移哨照旧（P3 改为观察项：router 即零参照，恒 ≈1 是构造使然）。

工具：`backend/scripts/probe_moe_components.py`（本文件先于该脚本首次运行写下；
v1.1 = 首过评审后修订，**仍先于首跑**：加 run 分桶防草稿件污染、探针固定开销 c
标定与校正比值、L=6 空桶与对照失败分开报、漂移哨、P5 改上界读法）。
口径：26b-8bit + 4bit 草稿件，生产装载路（排序阈值 16 生效，跑前断言）、
temp=0 / rep1.1 / ctx50 / 300 tok；生成序：off①→block4→block6→off②（漂移哨）
→block4（排序辅助单测）；逐组件 `mx.eval` 插桩，**只采信比值**，
且测得比值恒为真值**下界**（每调用固定开销 c 与 L 无关，压低比值）。

## 可证伪预测（按判定力排序）

- **P1（阳性对照，先于一切结论）**：稠密量化组件（dense MLP、lm_head）的
  t(L=6)/t(L=4)（原始值）∈ [1.5, 2.2] —— qmv_wide 瓦片数在 M=6 处从 1 变 2。
  **<1.3 判探针不可信，整组作废（退出码 2）**，不许解释、不许挑着用；
  [1.3,1.5) 或 >2.2 = 出预测带，通过但判读降级。
  **L=6 桶为空是另一种失败**（block6 未生效/截断，退出码 3），单独报，
  不许错记成对照失败。
- **P2（主判据，用减 c 校正值；测得值恒为真值下界）**：Experts 的 t(L=4)/t(L=1)：
  - 校正后 ≥ **2.15** ⇒ 残差集中在专家内核的逐对重读（参照 **2.235~2.245** =
    v(4)=1.461~1.465 与修正字节账反算的有效专家倍率），S2（E=8 对撞）值得跑；
  - 校正后 ≤ **1.95 且 c 占 L=1 组件时长 <5%** ⇒ 贴近纯字节下限 **1.925**，
    缓存已把去重做满，内核线到此为止；
  - 其余（含 1.95–2.15 灰区、c 占比大）⇒ 预先承诺**不强判**，改跑 S2 直接量。
  - 我押 **校正后 2.1–2.35**（即残差大部分在专家内核）。依据：+9% 排序收益说明
    缓存回收显著但内核仍逐对发起读取，SLC 接不住 808MB/层的全程轮换。
- **P3**：Router 的 t(4)/t(1) ≤ 1.2（字节 0.3%、派发次数与 M 无关）。
  若显著 >1.2，我对路由成本的先验错，需单独查。
- **P4**：Attention 的 t(4)/t(1) ∈ [1.0, 2.0] 且占探针态步时 <15%
  （ctx 只有 ~60–460，KV 扫描便宜）。
- **P5（上界读法，v1.1 修订）**：排序辅助（_gather_sort+_scatter_unsort×层数）
  的**探针态上界** < 2% 的 v(4)·T1 ⇒ 排除、不值得动。
  上界 ≥2% ⇒ **不可据此立项**（探针把 µs 级算子抬高数倍，属混口径），
  要立项必须先做无探针 A/B。原 v1.0 写"实测 >2% 就升级动作"是混口径，作废。
- **P6（量级自检，非判据）**：探针态组件和 vs 无探针参照 18.4 ms 只查数量级；
  两口径探针开销不同，不设 ±25% 硬阈（v1.0 的 ±25% 承诺作废，理由同上）。
- **漂移哨**：off②/off① 逐组件最大偏移 >5% ⇒ t4/t1 判读降级为"方向性存疑"。

## 结果读法的预先承诺

- P1 失败 ⇒ 全组作废，重新设计探针（不得只丢弃失败的格）。
- P2 灰区/下界不可判 ⇒ 不强判，改跑 S2 用对撞直接量。
- 任何结论只写比值与判定，不把探针态绝对 ms 写进任何定档表。
