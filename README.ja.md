# Agent

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

[macOS 版をダウンロード](https://github.com/enkin-japan/Agent-L0/releases/tag/updates)

Agent は、Mac やブラウザーから使えるローカル優先の AI デスクトップアシスタントです。調べものや資料の整理、ファイルの作成など、いくつかの手順が必要な作業も自然な言葉で頼めます。iPhone と iPad からも、稼働中の Agent に接続して利用できます。

モデルは Apple Silicon 搭載の Mac で動かすほか、MLX または CUDA に対応する別の PC に任せることもできます。

## できること

- Web ページ、PDF、文書、画像、音声などをもとに調査し、要点をまとめる
- 資料を個人用ナレッジベースに保存し、後の会話で検索する
- 作業の進み具合を確認し、必要な操作を承認したり、タスクを止めたりする
- 生成したファイルを受け取り、プレゼンテーションをプレビューする
- 定期タスクを設定し、実行結果や履歴を確認する
- 自分のサービスを API ツールとして接続する

たとえば、「この PDF を読み比べて、結論の違いをまとめて」「この資料からプレゼンテーションを作り、まず構成を見せて」と頼めます。利用できる機能は、選んだモデル、接続したサービス、許可した操作によって変わります。

## 使い始める

### クライアントから使う

macOS アプリは、この Mac 上で Agent を動かす方法と、別の推論用 PC に接続する方法があります。アプリの設定でサービスへの接続を済ませてください。別の PC を使う場合は、そのアドレスと接続キーも設定します。

iPhone と iPad はクライアントとして稼働中の Agent に接続します。モデルは iPhone や iPad では動かしません。別の端末から接続するときは、Tailscale など信頼できるネットワークを利用してください。クライアントの詳しい案内は[Apple クライアントの説明](apple-app/README.md)をご覧ください。

すでに Agent が用意されている場合は、ブラウザーでその Web アドレスを開きます。同じ Mac で動かしているときの既定のアドレスは `http://localhost:5173` です。

### 自分でセットアップする

Python 3.11〜3.13 と Node.js/npm が必要です。モデルを動かす PC には、選んだモデルに応じたメモリまたは GPU メモリも必要になります。初回のモデル読み込み時には、大きなファイルをダウンロードすることがあります。

リポジトリのルートで依存関係をインストールします。

```bash
./devctl.sh setup
```

次に、使い方に合わせて設定します。

| 構成 | 設定と起動 |
|---|---|
| 1 台の Mac で使う | `config.yaml` の `inference.mode` を `inprocess` にします。`rag.compute.host` は空にし、`.env.local` に `RAG_COMPUTE_HOST` があれば削除します。その後 `./devctl.sh start` を実行します。 |
| 推論用 PC を別にする | 2 台それぞれにアドレスと接続キーを設定します。推論用 PC では `./devctl.sh start --profile gpu`、Agent を使う側では `./devctl.sh start --profile edge -h <推論用PCのアドレス>` を実行します。 |

初期設定の `inference.mode` は `remote` ですが、接続先アドレスは入っていません。接続先を設定せずに起動するとエラーになります。1 台で使う場合は、上記のとおり `inprocess` を明示してください。分離構成のアドレスとキーの設定方法は[構成の説明](ARCHITECTURE.md)をご覧ください。

起動したら、ブラウザーで `http://localhost:5173` を開きます。状態の確認、ログの表示、停止には次のコマンドを使えます。

```bash
./devctl.sh status
./devctl.sh logs backend
./devctl.sh stop
```

会話モデルやナレッジベースのモデルを変更する場合は、設定ファイルを直接編集せず、選択コマンドを使います。

```bash
./devctl.sh model
./devctl.sh rag-model
```

ナレッジベースのモデルを変更した後は、macOS アプリのナレッジベース画面に表示される案内に沿って再構築してください。「後で」を選んだ場合も、この画面に戻って再構築できます。

## 日々の利用

ファイルを会話に添付し、どんな結果がほしいか伝えてください。作成されたファイルはファイル画面から確認でき、プレゼンテーションは Deck 画面でプレビューできます。セッションと生成ファイルには保管期限があります。大切な会話はピン留めしてください。具体的な期限はアプリに表示されます。

操作の確認が表示されたら、内容を確かめてから承認してください。定期タスクが無人で実行される場合、承認が必要な操作を自動で許可することはありません。

停止をリクエストすると、安全に中断できるタイミングで後続の処理が止まります。ただし、停止前に完了したファイル操作や外部サービスへの操作は取り消されません。再試行すると、同じ添付ファイルと生成設定を使って処理をやり直します。その過程でツールが再び呼び出される場合があります。承認が必要な操作には、再試行時も確認が求められます。再試行が成功すると会話には新しい結果が表示され、それまでの試行も引き続き確認できます。

自分の API を接続する場合は、macOS または iOS アプリの設定から API ツールを開き、接続先やキーを入力します。ツールを一覧に追加しただけでは、接続やキーが確認済みになったわけではありません。試しに実行すると実際の操作が行われる場合があるため、内容を確認してから実行してください。

## データとプライバシー

会話履歴やナレッジベースは、Agent を動かす作業用 PC に保存されます。別の PC で推論する構成では、処理に必要な入力がその PC に送られます。Web 検索、自分で接続した API、クラウドアドバイザー機能を使うと、それぞれのサービスにも必要な情報が送られます。

推論用 PC には、画像や音声などのメディアが一時的に保存されることがあります。KV キャッシュの永続保存は初期状態では無効ですが、有効にするとセッションに関連するキャッシュも保存されます。保管期限や削除の設定は[構成の説明](ARCHITECTURE.md)をご覧ください。

サービスには信頼できるネットワークから接続してください。Web のアドレスにアクセスできる端末は Agent を利用できるため、インターネットへ直接公開しないでください。
